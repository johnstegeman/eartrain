# Guitar Sample Attribution

The WAV files in this directory were extracted from the **FluidR3 GM soundfont**,
created by Frank Wen and maintained by the FluidSynth project and MuseScore.

## Source

- **Soundfont:** FluidR3Mono_GM.sf3  
- **Author:** Frank Wen (`get-the-beat@usa.net`)
- **Maintained by:** MuseScore community  
- **Source repository:** https://github.com/musescore/MuseScore (share/sound/)
- **Format:** SF3 (compressed SoundFont 2), extracted here as 16-bit mono WAV at 44100 Hz

## What Was Extracted

- MIDI notes 40–81 (E2 to A5), covering the full playable interval range in EarTrain CI
- Three guitar timbres (GM programs):
  - `acoustic_steel/` — Acoustic Guitar (Steel), GM program 26
  - `clean_electric/` — Electric Guitar (Clean), GM program 28
  - `overdrive/` — Overdriven Guitar, GM program 30
- 42 notes × 3 timbres = 126 WAV files total
- Each note: 2.2 seconds (2.0 s sustain + 0.2 s release tail), mono, 44100 Hz, 16-bit PCM
